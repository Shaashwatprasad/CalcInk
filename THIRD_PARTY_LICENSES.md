# Third-party model and runtime inventory

CalcInk's pretrained symbol checkpoint is derived from Rafi Ibn Sultan's [Math_Symbols_Classify](https://github.com/rafiibnsultan/Math_Symbols_Classify), commit `0f90d32afb1e4d8416b3d0c4adf4ce1748d86a16`, file `modelWeight_dataset2.h5`. The repository distributes these weights and its architecture under MIT, copyright © 2021 Rafi Ibn Sultan. The unmodified complete notice is retained in `public/models/LICENSE` and shipped beside the derived ONNX file. Upstream contains no separate weights restriction. Dataset II training-data rights are not independently established; CalcInk does not redistribute the training dataset. The model's training-data provenance and missing live validation are recorded in `docs/MODEL-AUDIT.md`.

ONNX Runtime Web 1.22.0 is distributed under MIT, copyright © Microsoft Corporation. The npm package omits a root license file; the upstream v1.22.0 MIT notice is vendored in `public/runtime/LICENSE` for production delivery. The asset preparation script retains that notice beside the matching local WASM/MJS files. React, React DOM, Vite, TypeScript and the development tools retain their upstream notices in installed packages; exact versions and transitive dependencies are pinned by the lockfile. No remote runtime or inference service is used.
