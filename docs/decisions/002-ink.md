# ADR 002: Vector ink, scoped erasure masks and Canvas2D layers

Status: implemented; browser/device performance and antialias validation remain pending.

## Context

Drawing must remain usable during recognition. Saved ink, undo/redo and recognition rasterization must preserve partial erasure. Removing pixels from the displayed canvas alone loses the erasure on replay; applying a global mask also incorrectly removes later strokes.

## Decision

`InkStore` owns immutable document snapshots. One completed pen or eraser gesture creates a transaction. Undo/redo restore vector content while increasing the document revision. Clear also increments generation; document recovery assigns a new generation. History defaults to 100 transactions and is configurable through the constructor. Current ink/masks persist; undo history is session-local.

Partial erasure stores a swept round path, radius and the IDs of intersecting strokes present at erasure time. Replay draws each masked stroke into a scratch Canvas2D layer, applies its masks using `destination-out`, and composites that isolated layer into the destination. Other strokes retain their ink regardless of draw order. The same `drawDocument` and `drawStroke` functions accept normal or worker OffscreenCanvas contexts for recognition.

Pen strokes use round polyline capsule geometry and single-point circles. The active renderer appends pending samples once per animation frame. Committed ink is replayed once per invalidation, including resize, edit and history changes. Coordinates remain CSS/document units; only backing canvases scale with device pixel ratio. Coalesced events and the final pen-up endpoint are retained even when pen-up occurs before the first frame. Cancellation and capture loss commit the partial gesture already received. Eraser paths preview on the active layer, then commit once at gesture completion.

## Alternatives

Geometric splitting avoids a scratch canvas but makes intersections, rounded boundaries and reversible fragmentation substantially more complex. A global raster mask does not preserve target IDs. Persisting only a bitmap would lose editable vector geometry and resolution independence.

## Evidence and consequences

Unit tests cover transaction/history semantics, sparse-path segment intersection, masks surviving JSON recovery, scoped compositing above/below other ink, incremental/replay capsule equivalence, rapid completion, dots, coalesced events, cancellation, scroll/resize/DPR and cleanup. The raster unit fixture uses binary geometry: it does not substitute for browser antialiasing, physical stylus/touch checks or frame-time measurements.

Full committed replay and one scratch layer reused per replay prioritize correctness. Large-document redraw/hit-testing performance remains to be measured; no universal frame-rate claim follows from this design. Stroke hit testing currently targets underlying vector geometry, so a stroke whose visible pixels are fully masked may still be removed by the stroke eraser. Recognition applies persisted masks before classification.
