# Validation

Run `npm ci`, `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test` and `npm run build`. Browser checks use the production output: `npx playwright install chromium`, `npm run test:e2e`, and `CALCINK_PRODUCT_REQUIRED=1 npx playwright test --config playwright.product.config.ts`.

Unit/integration regressions cover arithmetic, generalized variables, definition rebinding, cached ASTs/results, revision races, 200 independent equations, status-only answer-array stability, grouping merges/splits/fractions, both erasers, undo/redo, pressure/alpha, retained redraw, object editing/lasso, persistence, pen-up autosave scheduling and derived history. Production browser tests run the actual model and cover drawing/editing, offline reload, notebook switching, annotations, typed math, diagnostics and UI controls. Synthetic geometry and fake worker messages are labelled test fixtures, never production recognition.

`npm run test:ml` and `npm run test:product` retain exact commands, counts, source identity and browser reports in ignored test-results. Reusable measurements live in benchmark and compact outputs in docs/benchmarks. Record actual browser/CPU/runtime; do not convert a Node evaluation benchmark into an inference or FPS claim.

For offline validation, load production on localhost/HTTPS, wait for Offline ready, disable network, reload, draw/edit a real-model fixture and verify undo/redo plus persistence. Keep network observations: inference/runtime/math must have no remote dependency.

Human handwriting quality is a separate open evidence requirement. The corpus in scripts/benchmark/corpus/empty.json intentionally has zero human samples. Capture and independent annotation tools remain available under scripts/benchmark/capture. No writer-diverse accuracy, physical stylus/touch certification, universal 60 FPS or WebGPU benefit is claimed.

The drawing measurements include two distinct workloads. `render-benchmark.mjs` isolates native Canvas rendering and compares active frames with canonical replay at DPR 1 and 2. `notebook-benchmark.mjs` verifies 20 separate solved synthetic equations in the actual production app, keeps real recognition and autosave enabled, and measures continued drawing in a fresh browser context. On Apple M5 / Chrome 155 the recorded baseline and candidate both had frame-interval p95 near 16.8 ms; severe jitter was not reproduced. The candidate reduced active cleared pixel area from 843,864,480 to 190,580 and notebook writes during active gestures from 18 to zero. These are work-reduction measurements, not a claimed frame-rate speedup or a physical-device result. See `docs/benchmarks/notebook-latency.json` and `render-retention.json`.
