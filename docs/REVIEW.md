# Independent integration review

Reviewer role: math implementer independently reviewed ink, recognition, app, persistence, offline and root configuration. The math/projection author did not approve their own implementation; that separate review is recorded in `docs/REVIEW-MATH.md`. Review date: 2 October 2026. Candidate branch: `codex/feat/calcink-baseline`; shared working tree, no reviewer Git mutations.

## Findings and repairs

1. **Deployment path blocker, repaired in source.** Worker originally resolved `./` against the origin, yielding `/models/manifest.json` and `/runtime/` under a `/CalcInk/` deployment. Reproduction: `new URL('./', 'https://example.github.io').href` returns the origin root. Production worker now resolves `../` against its emitted `assets/recognition.worker-*.js` URL. A subpath browser deployment check is still required.
2. **Active gesture retirement blocker, repaired and tested.** Clear/import while a pointer gesture was active could commit pre-clear ink into the replacement document at pointerup. `mountInk` now retires the gesture and releases capture on clear/replace. `tests/unit/ink-pointer.test.ts` exercises both transitions; independent ink tests pass.
3. **Malformed worker payload blocker, repaired and reproduced.** A valid envelope with `strokes:[null]` originally threw while reading `id`. The runtime validator now checks nested record values; direct Node reproduction returns false and the recognition regression tests pass.
4. **Imported bounds blocker, repaired in source.** `bounds:{}` passed the original `Object.values(...).every(...)` check, producing undefined grouping geometry and invalid eraser hit tests. Imported bounds now derive from validated points and width rather than trusting file metadata.
5. **Import/recovery race, repaired in source.** Import controls were active during asynchronous storage recovery; a late saved document could overwrite an import. Import/export are now disabled until recovery finishes. Live app regression evidence is pending.
6. **Synthetic browser pointer fixture, repaired in source.** Synthetic PointerEvents lacked `isPrimary` and did not establish a real captured pointer, so the high-DPI E2E fixture could fail without testing the app. It now uses actual Playwright mouse input; rapid no-frame pen-up remains covered independently in unit tests.
7. **Silent recognition failure, repaired in source.** A `RESULT status:error` was followed by global Ready for handwriting, hiding the failure. The app now enters error/retry state, terminates the worker and clears projections. Worker OffscreenCanvas capability is checked before READY.
8. **Save badge identity race, repaired in source.** An old document's revision 1 save could finish while an imported document also had revision 1, causing a premature Saved badge before the imported write completed. Save status now compares document ID, generation and revision for both success and failure callbacks. Serialized IndexedDB writes themselves preserve final order.
9. **Model HTTP-cache collision, supervisor reproduced and repaired.** Concurrent model/cache population produced Chromium `ERR_CACHE_WRITE_FAILURE`. Worker model/manifest fetches now use `cache:'no-store'`; service-worker CacheStorage still serves those requests offline. Source review accepts this separation, and the supervisor's production browser rerun passes.
10. **Frame-monitor accuracy, repaired in source.** The first visible rAF interval after hidden-tab suspension could include the whole hidden gap. The prior timestamp now resets on visibility changes, and cleanup removes that listener. The over-budget threshold now uses the explicit 60 Hz budget of `1000/60` ms. Sampling is bounded to 600 intervals; callbacks run once per second, and rAF/timer/observer cleanup is present.
11. **Worker-grouping scheduler follow-up, repaired and independently tested.** Grouping was moved off the main thread after the supervisor observed approximately 223 ms for the previous main-thread 5000-stroke grouping workload. Independent FakeWorker/fake-timer tests exercise latest-revision debounce, immediate invalidation, unrelated equation preservation, stale groups after clear/recovery, cooperative old recognition replies and grouping timeout/disposal. A direct grouping-tolerance mismatch was reproduced and repaired by matching the worker's 0.6 height expansion. A further reproduced cascade—lines at y=0..40, 120..160 and 220..260 plus new tall ink at y=0..100 merging into one worker group—originally left the third old answer visible while awaiting GROUPS. Invalidation now computes a conservative closure over known equation bounds so cascading dependencies retire immediately. It leaves unrelated answers/jobs valid. Main-thread full-document grouping is removed; runtime response validation and structured-clone transfers still require performance measurement.

## Remaining blocking assessment

The candidate is not approved for the complete submission release. The real-worker E2E initially checked READY and logged UI text without asserting an expression or answer; that would only prove loading/warm-up. Its stronger arithmetic/edit/offline assertions now pass in the supervisor's production run. Synthetic fixtures do not replace writer-diverse live samples or prove accuracy.

The visible recognition failure, save-status identity, HTTP-cache, worker-base, metrics and worker-grouping scheduler repairs are accepted in source review and the relevant regression checks above. No unrepaired implementation blocker was found in the examined candidate. The baseline is acceptable for integration/merge under applicable policy after combined checks and required CI pass. This review does not satisfy the outstanding submission release evidence or authorize bypassing required checks. The final model functional-browser report is recorded in `public/models/browser-verification.json` with its synthetic-fixture and alternate-browser limitations.
