# Delivery status

7 October 2026 — incremental equation tracking/evaluation, retained rendering, typed math, text/lasso editing and Current/History are implemented and independently reviewed. The base application was integrated through [PR #6](https://github.com/Shaashwatprasad/CalcInk/pull/6), merge `cd6fdf0`; [PR #7](https://github.com/Shaashwatprasad/CalcInk/pull/7) records the follow-up integration status. Repository handoffs, raw task logs and obsolete scaffolding were removed; README and architecture describe the actual product.

Passed on the follow-up source: typecheck; lint; formatting; 297 unit/integration tests; 4 registry contract tests; 14 browser preprocessing contracts; production build; 8 real-model/offline E2E cases and 45 product browser cases. Browser validation used isolated preview ports with headless Chrome 155 on Apple M5. Synthetic regression evidence does not imply handwriting accuracy or physical stylus certification.

Multiple-row recognition now compares bounded segmentation candidates instead of rejecting clear text solely because a speculative split exists. Ordinary broad digits and horizontal minus bars avoid false uncertainty flags; conflicting readings and omitted hypotheses remain uncertain. One equation error no longer clears unrelated answers or stops later jobs, and known dependency hints survive a failed transcription. A real-model regression draws three equations, edits the middle row, preserves other answers and reloads all three. Four clear rows in the unchanged reported notebook were verified as 3, 6, 6 and 3; tightly overlapping ink still has competing readings. Development startup now prepares its matching local runtime assets.

Measured 200-equation edit: one recognition job, one parse and one evaluation; 199 unchanged projection references, all answers retained. Candidate grouping carried 18 strokes versus 1,200 previously. Renderer callback p95 fell from 6.4 ms to 0.6 ms in the separate controlled workload. Reusable scripts and compact environment/results remain under benchmark and benchmark-data.

Both hosted check runs passed on application commit `3954649`, including the complete ML/product report validators. The merged tree matches the verified local application. The earlier V2 candidate from PR #5 is included in this integration.
